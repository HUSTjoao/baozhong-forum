# 专业目录整理记录

核对日期：2026-10-10。现有目录整理为 192 个不同的本科专业：文科 47、理科 27、工科 76、医科 22、其他 20。本次新增 56 个常见专业，重写 41 个过短介绍，并修正新闻学、国际政治、系统科学与工程及预防医学的介绍。

## 分类依据

专业名称和代码依据教育部《普通高等学校本科专业目录（2026年）》。本站五个入口属于展示分组，不代表高考选科要求或授予学位类型：

- 文科：哲学、经济学、法学、教育学（体育除外）、文学、历史学、管理学。管理类中的物流工程也依目录归入此入口。
- 理科：目录中的理学专业，包括心理学、应用心理学、生物信息学和系统科学与工程。
- 工科：目录中的工学专业，包括智能科学与技术、制药工程、生物医学工程、材料物理、环境科学、工业设计、农业机械化及其自动化、森林工程和酿酒工程。
- 医科：目录中的医学专业。医学影像技术和眼视光学也放在这一入口，不据此声称授予医学学位或能直接从事医师工作。
- 其他：农学、艺术学、体育学类。园林（农学）与风景园林（工学）、动物医学（农学）与临床医学（医学）分别处理。

官网目录与部分高校的授予学位可以跨门类，不按名称关键词或学位名称重新改动展示分组。新专业也必须填写正式类别，不能再用“设计”“管理”“动物”等词自动归到其他。

教育部依据：[发布通知](https://www.moe.gov.cn/srcsite/A08/moe_1034/s3882/202604/t20260427_1434931.html)、[目录原文 PDF](https://www.moe.gov.cn/srcsite/A08/moe_1034/s3882/202604/W020260427440749576927.pdf)。仓库中的 `major-catalog-2026.json` 为核对用的代码与名称摘录，页面数据存储在 `data/majors.ts`。

## 去重与旧链接

同名专业合并为一条；原先 `aerospace-engineering` 同时对应航空航天工程和飞行器设计与工程，现在飞行器设计使用独立 ID `aircraft-design`。新闻传播学作为大类名称改为正式的新闻学，国际关系改为国际政治，复杂系统科学改为系统科学与工程。

理论物理、应用数学、量子物理、微生物学、计算生物学、急诊医学、公共卫生没有作为独立本科专业列出。旧链接分别兼容到物理学、数学与应用数学、生物科学、生物信息学、临床医学和预防医学。没有删除用户或讨论数据。

运行 `node node_modules/tsx/dist/cli.mjs scripts/check-major-catalog.ts` 检查代码名称匹配、分类、英文、介绍完整性、重复项及旧链接。该检查同时防止本地已审核的同名专业再次覆盖正确分类。
