# 专业详情文字缺字修复

仅对专业详情中的动态中文标题、介绍与阅读区使用完整的霞鹜文楷，避免“工科”两字展示字体被用于整个专业名称，以及正文缺字时混入系统字体。介绍首字恢复正常大小、字形和基线。英文标题保留 Cormorant。

全站导航、专业分类标签及目录大标题、论坛、大学、寄语、登录、个人页和后台均保留原有字体与字号，不做视觉重设计。原来的两字装饰字体仅继续用于其完整覆盖的固定分类标签。

完整文楷由仓库已有、附带授权的 `profile-reading-wenkai.woff` 生成，8834 个字符覆盖当前全部专业名称与介绍。字体样式仅由专业详情页导入；其他页面没有引用新字体的选择器。使用 WOFF2、unicode-range 按需分片和常用 UI 优先包，避免整包下载。文件名带内容哈希，可缓存一年。

生成：`python scripts/build-site-fonts.py`（需 fontTools 与 Brotli）。定义为 `app/site-fonts.css`，清单为 `data/site-fonts.json`，资源为 `public/fonts/site/`。原授权在 `public/fonts/OFL-LXGWWenKai.txt`。不要在部署时清空字体目录，以保留旧页面缓存仍引用的哈希文件。

检查：`python scripts/check-site-fonts.py` 验证哈希、Unicode 范围、字符不丢失和专业文案覆盖。浏览器核对实际渲染字体、电脑与手机布局，并将导航、分类顶部和论坛的字号、行高、字重及尺寸与修改前样式比较。搜索输入、评论区间距和总览按钮定位是另外已确认的本地功能改动。

专业列表仅对卡片内的中文专业名称采用完整文楷，保持桌面 38px、手机 31px 及原行高；分类标签、目录大标题、英文与卡片介绍沿用原样。已在电脑和手机核对工科 85 个专业标题的实际渲染字体。
