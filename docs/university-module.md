# 大学介绍模块

## 当前资料范围（2026-10-09）

目录共有149所具名学校，149所均已填写独立的校园介绍、英文名称、官网与介绍来源。介绍以学校官网、学校章程和官方招生资料为依据，概述办学历史、学科特色与校园情况，采用统一详情模板。校园照片暂未录入。校徽文件数量不等于学校数量。

146所填写了校训。北大显示注明类型的学风、大连理工显示大学精神、北京林业显示办学理念，149所卡片和详情均有相应文化文字。新增31所校训及来源记录于 scripts/research/campus-mottos-reviewed.tsv；西安财经大学官网抓取受限，使用未来网高校专题的校训释义核对，并保留实际来源地址。其余新增校训依据学校官网或章程核实。学校层次依据教育部985名单、211名单与第二轮双一流建设名单整理，不将省级双一流、985创新平台等同于相应国家项目。资料不包含未经确认的排名、学生人数或虚构讨论。

发布资料保存在 `data/campus-profiles-reviewed.json`。新增131所学校的人工改写稿保存在 `scripts/research/campus-introductions-reviewed.tsv`，官网域名与英文名称目录保存在 `scripts/research/campus-websites.tsv`。采集程序只提供研究候选，自动抓取的简介不直接发布；原始网页缓存位于被忽略的 `node_modules/.cache/campus-research`。

## 本地导入

运行 `npm run db:seed:catalog`：脚本仅允许本地SQLite，先执行在线数据库备份，再同步目录中的已整理档案和学校层次。它会更新已有档案，因此后续人工编辑需同步回资料JSON，避免再次导入覆盖。备份位于被Git忽略的 `prisma/backups`。远程数据库未修改，旧用户与寄语不导入。

列表与详情通过Prisma读取数据库。University保存标识、城市和校徽；UniversityProfile保存新版资料。所有学校使用同一个学校介绍与校园讨论模板，不需要复制页面。

## 浏览体验

每页18所学校，桌面每行3所，学校陈列区域独立滚动；底部页码支持指定页跳转。地区与层次可组合筛选，查询条件写入URL。华中科技大学位于第八位，紧接着是西安交通大学。卡片收回保留查询和滚动位置。

首次进入大学列表时，标题、地图、筛选与卡片分批错落入场；同一次网页加载中，筛选、翻页和返回列表不重复播放；刷新网站后首次进入会重新播放。旧sessionStorage播放记录不影响触发。减少动态效果偏好下不播放出场动画。

地图使用城市中心位置，并非精确校区地址。来源与精度记录在 `data/campus-city-centers.json`。学校配色按标识稳定映射，保持统一视觉风格。
