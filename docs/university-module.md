# 大学介绍：第一版

## 结构

大学列表与详情读取数据库，详情共用一个模板。新资料存放在 UniversityProfile 表，旧描述不参与展示。University 只提供学校标识、名称、城市与保留的校徽。Question 通过 universityId 关联学校，通过 askerId 关联作者。

浏览器 → 服务端页面读取资料 → Prisma → 本地 SQLite（线上可用 PostgreSQL）。

发帖：浏览器 → POST /api/questions → 检查登录与数据库中的禁言状态 → 校验内容和学校 → 保存帖子 → 刷新讨论列表。

## 初始资料

第一版仅华中科技大学与清华大学，学校介绍和校训根据官方资料重新整理。详情页提供来源链接。校园照片暂未录入。没有虚构学生人数、排名或讨论。

本地初始化新资料：npx tsx scripts/seed-university-profiles.ts。脚本只在 SQLite 环境运行；重复执行不会覆盖已编辑的档案内容。不要执行旧 db:seed 来初始化新内容。

添加另一所大学：准备校徽与官方来源，在 University 中建立学校标识，在 UniversityProfile 中建立对应档案；同一模板自动显示，无需复制页面。

## 当前范围

已包含搜索、地区筛选、统一详情、官网/来源入口、讨论列表与登录发帖。讨论详情暂时使用原有论坛页面，回复、点赞、审核及讨论的独立视觉设计留待论坛板块统一重构。

数据库同步前已备份到 prisma/backups，备份被 Git 忽略。SQLite 和 PostgreSQL 的 schema 同时增加档案模型，但尚未连接或更改远程数据库。

服务器上线前需准备正式迁移流程、独立空数据库、内容管理、日志轮转与备份。旧远程用户、寄语不导入新系统。

## 分页目录与背景配色（2026-10-08）

本地核对结果：149 条具名高校目录，校徽目录共有 154 个文件；不能将校徽文件数当成完整学校档案数。目前 18 所学校已有新核实资料，其他学校只有基本名称、所在城市及校徽，介绍、英文名、校训和未核实标签留空，页面明确显示整理状态。旧用户、寄语、旧学校介绍不导入。

执行 `npm run db:seed:catalog` 可接入目录；导入前使用 SQLite 在线备份，已有编辑内容不覆盖。官网核实记录在 `data/campus-profiles-reviewed.json`；首批包括北京大学、复旦、上海交大、浙大、南大、中科大、西安交大、哈工大、北理工、南开、天大、东南、武大、中山、华南理工、四川大学，加上原有华中科技大学和清华大学。北京大学未将网上常见口号冒充正式校训。

列表每页 18 所，使用底部页码；查询条件和页码写入 URL，卡片收回保留原页面地址。搜索和地区筛选回到第一页，越界页码限制到有效范围。学校配色由稳定的学校标识映射到六种浅色，已核实资料可指定配色。

新增学校地图终点使用 DataV 公开行政地图的城市中心，并非精确校区位置。华中科技大学和清华大学保留之前的校区点。数据来源和精度记录在 `data/campus-city-centers.json`，采集脚本为 `scripts/collect-campus-city-centers.cjs`。
