# 首页照片加载优化

首屏原来直接请求 4,097,466 字节的樱花 PNG，同时下载第二张轮播照片及页面下方的照片墙。校徽优化没有覆盖这些照片。

- 用 `node scripts/optimize-campus-photos.cjs` 预生成现有六张照片的 WebP 多尺寸版本，原图保留。首屏最大版本为 1,672 × 941、503,158 字节，比原图减少约 87.7%。不改变构图、显示尺寸、暗化和轮播过渡效果。
- 首屏照片使用匹配的响应式预加载和高优先级请求，内嵌微小预览作等待占位。响应式尺寸考虑 `object-fit: cover`，避免竖屏错误选用过小图片。
- 第二张照片在首图加载完成后延迟请求，并尊重可见性和减少动画设置。两张照片就绪后才开始轮播。首图失败时尝试第二张，包括预加载在 React 挂载前失败的情况。
- 照片墙接近视口后才插入轻量缩略图；点击放大时请求较大版本。保留拖动、动效、键盘操作和照片尺寸。
- 带内容哈希的照片资源设置一年不可变缓存，图片变更通过新文件名更新。

本地生产构建及桌面、390 像素移动端浏览器验证：首次请求只含一张 503,158 字节的背景照片，照片墙无提前请求；轮播、照片放大/切换/关闭、移动端无横向溢出、减少动画及首图失败回退均检查。网络限速属于本地模拟，不代表公网实际速度。

上线只需拉取代码、构建并重启现有 PM2 进程，不涉及依赖安装、数据库结构或目录数据同步。本地完成不表示公网已更新。
