# 掌上高考逐校补查（2026-10-25）

## 本轮结果

- 对网站全部149所大学逐一匹配掌上高考正式名称并读取公开的陕西年份、科类索引；两所军校使用页面中的完整校名核对，149所全部匹配。
- 按已发布的年份和科类完成304项查询，使用页面实际采用的每页5条分页，共读取1036条原始分组记录。
- 排除5条艺术体育综合分或分数位次未公布的记录，1031条普通高考口径候选通过陕西同年同科类位次区间核验；全部保留为第三方公开参考。
- 80项查询在首屏或后续分页返回“身份授权失败”，停止该项后续访问；64个已取得部分记录的学校年度并非完整表。没有登录、绕过授权或获取付费资料。
- 本地展示由1721条增加至2106条，净增加385条；原有学校官方数据未被参考来源覆盖。
- 新增南方科技大学2024年提前批C段参考、东北林业大学2026年、西藏大学2026年；另补26处原先完全空白的年度科类。科类有记录不代表普通本科批已齐全，例如军校提前批单列。

## 掌上高考本身的陕西年份缺口

其公开索引中，17所大学有陕西2026年数据，144所大学有陕西2025年数据。其他省份2026年已经更新，不代表陕西同年数据也已发布。

南京大学陕西索引仅列2025、2024、2023、2022、2021，没有2026；本轮没有用2025年的658分填2026年。

以下学校在该平台没有2025陕西普通高考分数入口：安徽师范大学（仅列2021）、中央音乐学院（列2023、2022、2021）、首都师范大学、上海中医药大学、汕头大学。索引没有记录不等于当年未招生；汕头大学2026首次在陕招生另有校方说明，首都师范大学2026在陕艺术综合分单独说明，不混为普通分数。
