# 讨论详情与专业讨论链路

详情页 `/forum/[id]` 使用问题区、回答区和楼中楼评论布局，提供回答排序、全文展开、匿名回答/评论、赞同、复制链接、举报及本人/管理员删除入口。标题采用思源宋体，正文 20–21px，作者、日期和按钮保持清晰字号；输入遵循全局无矩形焦点框、无缩放角标规则。

专业列表、发表和回复已使用数据库 API；按 majorId 从服务端筛选，展开回复再拉取详情，查看讨论进入同一个详情页。旧浏览器 localStorage 草稿仍保留，但尚未自动迁入数据库。

`discussionTree` 兼容旧嵌套响应和当前平铺响应，避免遗漏深层评论并防止循环关系。详情接口读取全部层级；回复接口校验父评论所属问题和 3000 字限制。

开发模式的论坛示例进入相同详情页，示例回答与评论仅保留于当前组件状态，不向数据库发送写入请求。生产环境没有该示例分支。

验证：类型检查、界面嵌套评论/排序/赞同/匿名表单/手机布局、专业发表到详情的请求链路；数据库临时样本验证问题到两级评论、列表筛选及错误父评论/过长内容/未登录请求的拒绝。样本在验证后清除。

补充验证：真实数据库中的问题/回答赞同、非本人删除拒绝、回复所属问题校验、嵌套删除及回复计数、问题连同回复和点赞一起删除。全部使用临时样本并在结束后清除。
