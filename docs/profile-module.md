# 个人主页

## 设计

参考 Facebook 的封面、重叠头像和个人时间线结构：
https://about.fb.com/news/2011/09/tell-your-story-with-timeline/

主页不使用背景图或大封面。上方为浅蓝灰 Ghost Fibers 纤维舞台，横版校园名片从顶部垂下；姓名、身份、学校、专业、头像与贡献统计均集中在名片上，背面展示个人介绍。翻面、复位、编辑和分享集中在名片下方操作栏，移除左右重复资料。下方为浅色阅读区，以 Card Swap 叠卡呈现动态。名片使用宝鸡中学校徽、昵称、头像、身份和贡献统计，点击翻面查看介绍；支持拖拽、弹性回摆、键盘按钮翻面及复位。手机改为上下布局。

卡面视觉借鉴 React Bits Profile Card 的渐变边框、头像融合与光泽层次，保留横版挂绳。通过现有 Lanyard 材质加入低强度全息光泽，不复制 Profile Card 的页面结构或替换物理交互。

挂绳直接采用 React Bits Lanyard 开源组件：https://reactbits.dev/components/lanyard 。源码保存在 `components/profile/ReactBitsLanyard.jsx`，保留原版 Three.js 渲染、弹性和扭转计算，仅增加翻面、复位与状态回调；本项目的校徽卡面由 `badge-artwork.ts` 绘制。原项目 MIT + Commons Clause 许可保存在同目录 `REACT-BITS-LICENSE.md`。WebGL 不可用时显示静态资料，页面隐藏或名片离开视口时停止渲染。

## 数据与权限

动态筛选栏根据 React Bits Pill Nav 源码适配为本地 tab 按钮，使用原版圆形扩张尺寸计算与双层文字翻动设计；去掉路由、品牌 Logo 与手机菜单，以浏览器原生 Animation API 实现，避免引入额外路由和动画依赖。适配源码位于 `components/profile/ProfilePillNav.tsx`，沿用 React Bits 许可。选中项持续高亮，支持方向键、Home/End，减少动态效果偏好下即时切换。

动态区域使用 React Bits Card Swap 原版弹簧叠卡交互，源码为 `components/profile/ReactBitsCardSwap.jsx`，沿用同目录 MIT + Commons Clause 许可。移除原版演示图标与图片，接入真实动态；增加后排内容的键盘焦点隔离和拖拽后的点击保护。支持上一张/下一张、自动轮换、暂停、方向键、拖拽甩动；悬停及阅读时暂停，减少动态效果偏好下关闭自动轮换。筛选、搜索与更多分享仍由个人主页数据逻辑控制。

- `/users/[id]` 从 `/api/users/[id]` 获取数据库资料，替代旧浏览器存储逻辑。
- 公共资料接口不返回邮箱、密码、登录账号和禁言等内部字段。
- 访客只看到非匿名提问/回答及已通过审核的寄语；本人可看到自己的匿名内容与待审核寄语。
- 编辑接口仅允许本人操作，采用字段白名单，不允许修改账号、密码、邮箱或角色。
- 昵称、介绍、头像、年级以及毕业生的学校/专业/毕业年份可以保存。头像在浏览器裁剪并压缩，服务端验证格式和长度。
- 修改资料后，导航栏重新从数据库读取昵称和头像。
- 本人的大学/专业资料申请展示数据库审核状态；旧浏览器申请没有在此次重构中迁移。
- 各类型展示最近 40 条动态，统计使用数据库总量。页面搜索只搜索这些已加载的内容。

## 预览

开发环境 `/users/preview` 是明确标记的虚构示例。预览编辑仅影响当前页面，不写数据库；生产环境不会启用该预览。

## 验证

类型检查、预览筛选/搜索/编辑/阅读、手机横向溢出和减少动态效果检查通过。
使用临时数据库账号与内容验证访客/本人隐私、统计、身份校验、资料保存与刷新、输入验证、账号字段保护；测试结束后清除临时数据。


背景直接采用 React Bits Ghost Fibers 的原生 WebGL 源码，保留动态纤维、鼠标光晕、可见性暂停和减少动态效果支持。使用稍浅的蓝灰底色、浅蓝光带和低像素倍率，与挂绳分别渲染。

卡面中文、数字统一使用本地思源黑体（SIL OFL），覆盖常用及扩展中文与基本拉丁字符，并按固定基线对齐。左上角返回使用浏览器来源历史，没有历史时返回首页。动态最多同时露出四张卡片，减小景深缩放、加大间距以减少重叠。


Dynamic cards use React Bits Border Glow (https://reactbits.dev/components/border-glow), the shared MIT + Commons Clause license, and uniform pale surfaces with pointer-following mesh borders. Titles use Source Han Serif; body and metadata use Source Han Sans. Card Swap remains the navigation interaction.

设计要求：字体和字号必须在校园名片、动态卡片及展开阅读态分别检查，不能保留默认弹窗排版。用户偏好有辨识度、清晰的字形和足够可读的字号；标题、正文、作者和日期应共享明确的对齐线。展开阅读态沿用 Border Glow，宋体标题与正文、黑体元信息，移动端单独调整字号与滚动空间。

持续设计偏好：用户明确拒绝截图中默认粗黑标题搭配普通系统黑体正文的弹窗样式。后续设计必须主动选择有辨识度、优美且可读的字体，不能只改 font-family 名称而未验证字形是否实际加载。标题、正文、署名分别检查字号、字重、行距和视觉对齐；避免默认粗体、细小辅助文字及千篇一律的排版。当前个人主页展开阅读标题与正文改用本地霞鹜文楷，标题 34–48px、正文 25px，手机标题 32px、正文 22px。每次调整必须检查实际展开态。

名片操作栏、拖拽提示和动态分类导航同步使用同一完整常用字霞鹜文楷字库，避免只替换阅读弹窗。桌面操作 20px、提示 21px、分类 25px；手机分别 16px、19px、21px。保留操作功能和 Pill Nav 原生动画。

用户随后澄清两处栏位需要同步的是颜色：操作栏和动态分类采用阅读卡片的蓝灰色系，浅冰蓝选中面与深色底形成对比，避免旧灰绿色操作栏、米白/金色分类按钮与页面脱节。
