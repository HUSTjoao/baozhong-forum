# 大学卡片尺寸与长名称排版

问题是长中英文名称换行撑高卡片：1440 像素窗口下，不同行高度分别约 223、257、305、297 像素；卡片上下内容区宽度原本基本相同，但行高不一致使列表看起来错位。

- 卡片及滚动网格行统一为 264 像素高，卡片宽度填满各自等宽列；上下内容区明确占满同一宽度。
- 中文名、英文名及校训分别使用固定排版区域，底部坐标和学校等级固定在相同位置。缺少英文或校训时也保留区域，避免尺寸随内容改变。
- 根据真实字体的渲染宽高选择能完整显示的最大字号，只缩小超过空间的文字；不删校名、不用省略号替代英文。保留完整标题提示。
- 使用 ResizeObserver 与字体就绪事件重新适配，兼容窗口缩放、筛选、翻页和字体切换；清理观察器、帧回调及事件监听。
- 桌面三列、较窄窗口两列、窄平板和手机一列，避免空间不足时过度压缩校名。原有字体、配色、校徽、地图联动和详情过渡保留。

验证：生产构建通过。浏览器在 1440、1000、390、320 像素下逐页检查全部 149 所学校：卡片宽高一致、上下内容区等宽、底部分隔线对齐、文字均在区域内完整显示、无卡片内容溢出。上述窗口中最小实际字号分别为 13.2、11.6、13.2、12.8 像素。另验证搜索、详情进入与返回、窗口缩放及无客户端异常，并检查电脑和手机截图。

此项只改前端排版，没有额外数据库变更；同批尚未上线的校园照片投稿功能仍需要单独按其文档执行数据库增量迁移。
